# JH-MUSE-WORK.05 — Owner-only live WorkSession readout

Date: 2026-10-18. Base main: `ad5830382d6c209dca63da41c93f2575d6ed2242`.

## What was already there
- `@jhadina/core-spine` owns the real `buildRuntimeWorkProjection` and `buildWorkSessionRuntimeProjection` functions; task statuses include `paused`, `blocked`, `waiting-approval`, lease recovery and exhausted retry budget.
- `SupabaseWorkSessionRepository` and `SupabaseWorkSessionTaskRepository` enforce `owner_user_id` predicates.
- Existing routes `/work`, `/activity` and `/approvals` are separate useful surfaces. No new queue, audit ledger, policy or permissions are created.

## Implementation
- `GET /api/jhadina/work-sessions/[id]/projection` verifies a session-backed Supabase identity (not a caller-supplied user ID alone), fetches the exact owner-bound session first, then exact owner-bound task rows, checks row owner/session lineage and applies the **canonical** projection. Exposes only a bounded read-only session summary and truthful `coverage: canonical-work-session-only`. Never returns provider secrets, lease tokens or idempotency keys. All responses `private, no-store`; errors are non-sensitive. Read errors fail closed.
- `/work` now supports a small portrait-friendly **manual session ID** readout: recorded task counts, human attention, blocked reasons, recent states, links to existing approvals and audit routes. A `?session=` link pre-fills the ID, but nothing is fetched or authorized until the user explicitly clicks **Read work**.
- An empty WorkSession shows **zero task evidence**, never "all caught up," since uncommissioned services do not have universal coverage.

## Adversarial source checks
- Owner with matching cookie-derived identity can read a matching session.
- Missing/forged identity fails, including header mismatch.
- Foreign/absent session produces not-found and cannot query task rows.
- Foreign task rows fail closed without leaking task details.
- Missing database or malformed session ID fails closed.
- Empty WorkSession never fabricates background work.
