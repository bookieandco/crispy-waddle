# Planning Core

Planning Core is Jhadina's general-purpose spatial and temporal planning subsystem.

## Responsibilities

- Interactive-map data contracts
- Layers and markers
- Routes and geographic measurements
- Spatial annotations
- Scenario planning
- Timeline-linked geographic events
- Planning registry
- Planning proposals

## Boundary

Planning Core is not an autonomous operational system. It may describe, calculate, visualize, compare, and record plans. Any proposal that could trigger an external action must cross Jhadina's existing policy/security boundary before reaching an Action Executor.

## Initial consumers

Planning Core is designed to support Jhadina and its legitimate product verticals, including logistics, travel, emergency planning, business operations, and other planning workflows.
