## .01 — External skill reference reconciliation
`MuseSkillCandidate` accepts **only externally supplied text** at a URL pinned to a full 40-hex commit and the upstream original `skills/<slug>/SKILL.md` path. Bounds text, validates name/description, computes SHA-256, runs canonical `SkillScanner`, and registers a **candidate with zero capabilities** in the existing `SkillRegistry`. It does not fetch, auto-update, approve, elevate or execute the text. Its preview is explicitly untrusted. This is not a complete YAML/SKILL.md installer or a replacement provenance store. Third-party imports and licenses need separate treatment.

## .02 — Interrupted task safety
`DurableAgentRuntime.executeNext` now refuses automatic execution when the current same-revision step is unresolved (running/pending/failed) or its completed receipt is missing a matching latest checkpoint. Terminal and approval-paused runs also refuse blind execution. `recover` inspects checkpoint without silently rewriting a live step pointer from older checkpoint data.

This intentionally favors **operator receipt reconciliation** over duplicate external actions. It does not add a new queue, claim that Supabase migrations ran, or commission durable production workers. Canonical WorkSession lease/replay authority remains unchanged.

## .03 — Deterministic outbound review
`OutboundSentinel` is a **non-authorizing preflight**: HTTPS exact origin allowlist, no private/numeric/localhost host, credentials, query, fragment, special port, or unsafe URL characters. No default allowed origin, no wildcard or inferred permission. A scanner cannot guarantee security alone: the actual Action Core browser provider must enforce DNS resolution, IP egress filtering, URL normalization, redirect denial/revalidation, cookies/headers isolation, response limits, timeouts and network-policy containment.

## .04 — Governed browser handoff
`GovernedBrowserSkillOperator` requires an already approved registry skill with `browser.read`, an `allow` token, nonempty caller-provided identity and Sentinel-reviewed URL before handing a `GET` with redirect/cookie/credential omission **to the canonical GovernedSkillCommandDispatcher**. Its Action Core type is `browser.fetch_read_only`; no handler is installed by this change. The bridge does not touch the network and cannot perform forms, clicks, posting, external account changes or purchases. Server identity must be bound from authenticated session at future integration, never from client/model claims.
