# Game Boy homebrew — 2048

The `2048.gb` ROM in this folder is original upstream code published by **Wyatt Ferguson**, not a commercial Nintendo title. It is distributed under the MIT license; see `LICENSE` and source code.

- Source: https://github.com/wyattferguson/2048-gb
- Verified upstream source commit: `167788105db659f2049dd2d537ee12f63d87b1e7`
- Exact original and redistributed Git blob SHA-1: `9bae43c7c020af603c64e4e049064e5cbfb183f8`
- ROM filename: `2048.gb`; ROM length: **32,768 bytes** (Game Boy)
- Controls: D-pad up/down/left/right shifts tiles; **Select** resets the board.
- The source has an MIT license and requires retaining the copyright and permission notice alongside redistribution.
- This file is explicitly offered as a **manual user-initiated download**. It is never automatically imported into IndexedDB or bundled into encrypted gaming backup archives.
- Jhadina’s Game Boy emulator is still not commissioned until approved runtime assets are installed and a real device acceptance test succeeds.

## To install with the phone
1. Tap **Download free 2048 Game Boy game** in the Game Boy lab.
2. Choose **Import your .gb / .gbc file** and pick `2048.gb` in the Files app.
3. To play, the approved EmulatorJS runtime must be installed on the deployed host. Passing ROM structural validation alone is **not** runtime compatibility certification.
