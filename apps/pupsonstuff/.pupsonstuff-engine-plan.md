# PupsonStuff Interactive Engine Integration

This marker reserves the PupsonStuff engine integration path for the Godot/Turbulenz-inspired interactive product experience. The implementation should keep Next.js/Three.js as the storefront and web 3D foundation, with engine-style interactions layered into the product scene rather than embedding a second full engine runtime.

Reference repositories:
- https://github.com/godotengine/godot
- https://github.com/turbulenz/turbulenz_engine
