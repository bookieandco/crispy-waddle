# PUPSON-HOST.01–.04 — no-charge commercial-host experiment
**Date:** October 15, 2026. **Status:** source-level assessment / build experiment, not public deployment.

Vercel Hobby is non-commercial only and unsuitable for the live PupsonStuff store. Vercel project creation also returned 403. Its current five-minute creative-worker cron cannot run on the Hobby plan. Do not modify the existing Jhadina Vercel project, downgrade the worker cadence, or silently provision a paid plan.

Candidate: Cloudflare Workers Free with OpenNext for Next.js. The published October 2026 limits include 64 MiB uncompressed Worker size and 10ms CPU/request. The existing Next.js 15 app includes native Sharp image processing, Stripe, Supabase, and asynchronous image work; all require build and real runtime validation. This is a **candidate**, not a working deployment.

The GitHub Actions workflow in this PR performs a standard frozen-lockfile Next build, then a completely **ephemeral** installation of OpenNext 1.20.11 and Wrangler 4.129.1, tries an adapter build and uses `wrangler deploy --dry-run` with no provider token. Failures are preserved as evidence and do not change existing production code or assets.

Before authorizing actual deployment: connect a Cloudflare account under owner control, verify compatible app routes and CPU use on an isolated preview, preserve `PUPSON_FULFILLMENT_MODE=dry_run` and both commerce flags `false`, validate private pet-media processing and dedicated Supabase, and verify background processing under a scheduler whose cost has been explicitly approved. Never attach a production domain or turn on live Stripe/Printify from a build test.
