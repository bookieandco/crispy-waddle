# Transcript doctrine now canonical

## 1. Advertising accelerates; it does not initiate proof

Paid is not the first attempt to rescue an unproven offer.

Canonical readiness progression:

```
ORGANIC_PROOF_REQUIRED
-> BOUNDED_PAID_TEST_READY
-> PAID_ACCELERATION_READY
```

Required evidence includes:
- qualified conversions;
- repeated winning content;
- shared-media proof;
- owned destination;
- permissioned capture/nurture;
- known contribution economics;
- acceptable CAC bounds.

This is implemented in `social-paid-acceleration-readiness.ts`.

## 2. PESO is one portfolio

Paid:
- governed accelerator after proof.

Earned:
- referrals;
- relationships;
- citations;
- mentions;
- collaborations;
- trusted creator/community transfer.

Shared:
- organic social;
- community;
- platform discussion;
- discovery.

Owned:
- websites;
- landing pages;
- email/direct fan;
- lead magnets;
- durable content/search assets.

Owned is the durable destination. Followers are not treated as owned audience.

## 3. Customer language is content evidence

Learn from:
- customer interviews;
- support;
- reviews;
- comments;
- forums/Reddit;
- search questions;
- objections;
- complaints;
- desired outcomes.

Do not invent pains to improve copy.

## 4. Brand content and conversion content have separate jobs

Brand:
- story;
- identity;
- entertainment;
- education;
- worldbuilding;
- trust;
- humor;
- usefulness.

Conversion:
- problem -> product mechanism;
- proof;
- objection handling;
- demo;
- reason to act;
- destination CTA.

Both are required.

## 5. Organic attention should become owned relationship

For suitable offers:
```
content
-> useful lead magnet / direct-fan attraction offer
-> explicit consent
-> email / CRM / fan identity
-> nurture
-> offer
-> purchase / stream / lead
-> repeat / advocacy
```

## 6. One primary acquisition surface, native repurposing elsewhere

Do not blindly post the identical asset everywhere.

Pick a primary acquisition surface using actual evidence:
- audience fit;
- production/operator fit;
- discovery longevity;
- native-format fit;
- commercial evidence.

Repurpose the thesis natively to other surfaces.

## 7. Faceless must still be recognizable

Faceless properties require:
- stable profile identity;
- consistent visual grammar;
- stable voice/narrator identity where applicable;
- original/source-safe media;
- recognizable recurring format;
- no interchangeable generic B-roll as the default.

## 8. Viral strategy is probabilistic

Jhadina may engineer:
- hook;
- novelty;
- participation;
- identity;
- emotion;
- humor;
- timing;
- seed diversity;
- shareability;
- business destination.

She does not control:
- feed allocation;
- stochastic network spread;
- competing events;
- audience response.

One spike is not proof.

## 9. Artist / brand world matters

For music and creator brands, content should test:
- story;
- worldbuilding;
- emotion;
- cultural reference;
- humor;
- nostalgia;
- lifestyle;
- belonging;
- recurring characters/locations/rituals;
- process when process is actually the desired audience signal.

The goal is not merely creator-peer attention. Measure listener/customer/fan transfer.

## 10. Consistency is a system problem

The operating system should remove daily blank-page work:
- audience-question bank;
- Story Bank;
- objection bank;
- campaign ideas;
- owned/earned/shared opportunities;
- content calendar;
- batch production;
- scheduling;
- performance learning.
